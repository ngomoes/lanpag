# 🔗 Link-in-Bio Page

Halaman *Link-in-Bio* modern, ringan, dan responsif yang dibangun menggunakan HTML, CSS (Tailwind CSS), dan JavaScript murni. Dirancang khusus untuk menampilkan portofolio developer, artikel/tulisan, serta etalase produk digital maupun fisik (eBook & merchandise) dalam satu tautan ringkas.

## ✨ Fitur Utama

- **Desain Minimalis & Elegan:** Terinspirasi dari tampilan *link aggregator* modern yang bersih dan mudah dibaca di perangkat mobile maupun desktop.
- **Dark / Light Mode Toggle:** Pengunjung dapat mengganti tema tampilan antara mode terang dan gelap secara instan.
- **Quick Share / Copy Link:** Tombol salin tautan cepat untuk memudahkan pengunjung membagikan profilmu.
- **Kategorisasi Tautan:** Mendukung sorotan rilis terbaru (*featured card*), daftar eBook, katalog produk/pakaian, artikel pilihan, serta integrasi langsung ke WhatsApp.
- **100% Static & Ringan:** Tanpa ketergantungan *backend* atau database, sehingga sangat cepat dimuat dan siap di-hosting gratis menggunakan GitHub Pages.

## 🚀 Cara Penggunaan & Kustomisasi

1. **Clone atau Download** repository ini ke komputer lokalmu menggunakan terminal:
   `git clone https://github.com/username-kamu/nama-repo.git`
2. Buka file **`index.html`** menggunakan *code editor* favoritmu (VS Code, Sublime Text, dll).
3. Sesuaikan bagian berikut dengan datamu sendiri:
   - Foto profil, nama tampilan, bio singkat, dan *verified badge*.
   - Daftar URL tujuan pada setiap tombol/kartu tautan (eBook, toko, artikel, maupun nomor WhatsApp).
4. Simpan perubahan dan lakukan *push* kembali ke GitHub.

## 🌐 Deployment (GitHub Pages)

1. Masuk ke halaman repository ini di GitHub.
2. Buka menu **Settings** > **Pages**.
3. Pada bagian **Build and deployment**, pilih branch **`main`** dengan folder **`/ (root)`**, lalu klik **Save**.
4. Tunggu sekitar 1–2 menit hingga website aktif dan dapat diakses melalui `https://username-kamu.github.io/nama-repo`.

- HTML5
